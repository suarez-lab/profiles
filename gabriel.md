## Interests

- **Modelling.** Turning a messy operational problem into something with a
  well-defined objective and a solution you can argue about.
- **Algorithms and complexity.** What the bound actually is, and whether the elegant
  approach survives contact with the input distribution.
- **Machine learning.** Supervised learning on tabular data: model comparison
  (logistic regression, random forests, gradient boosting), cross-validation and
  ensembling. Built under competition conditions, where the leaderboard is the
  only opinion that counts.
- **Mathematical software.** Python (NumPy, scikit-learn, XGBoost) for modelling;
  Maple for symbolic and numerical work on operators and orthogonal polynomials;
  C and Java when the runtime matters.

## Background

- **MSc thesis** — spectral and matrix analysis of the multiplication operator in
  discrete Sobolev spaces: boundedness, point evaluations, zero localisation. I
  introduced an index extending Gelfand numbers to potentially unbounded operators
  and proved that where it stabilises identifies the unbounded point evaluations.
  Computational side in Maple, on Hessenberg matrix representations and singular
  values.
- **BSc thesis** — zeros of Sobolev orthogonal polynomials: algorithms to compute
  and visualise the zero sets, related back to operator norms.
- **Software engineering internship** (2024–2026) — Java and React services and
  REST integrations inside an enterprise content platform, with Maven, Git and
  CI/CD.
